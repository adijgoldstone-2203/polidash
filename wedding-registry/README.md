# Premium Wedding Registry Application

A minimalist, responsive, single-page wedding registry application built with HTML, CSS (Tailwind CSS via CDN), and Vanilla JavaScript.

## Features

- **Elegant Aesthetics**: A custom palette featuring Deep Plum (`#582A3A`), pale blush background accents, and serif headings (`Playfair Display`).
- **Responsive Card Grid**: Multi-column product layout with smooth hover transitions, NIS price formatting, and dimming indicators for claimed items.
- **Interactive Modals**: Smooth-opening popup forms with native browser input validation.
- **Verbatim Banking routing & success modal**: Clean presentation of transfer options.
- **Hybrid Realtime Database Sync**: Built-in support for **Supabase Realtime** and **Firebase Firestore** with an automatic **Local Storage fallback** (perfect for local testing and out-of-the-box demoing).

## Getting Started

1. **Clone/Move** into the project folder:
   ```bash

   ```
2. **Open** `index.html` in your browser (either directly or via a local server like Vite/VS Code Live Server).

## Database Sync Setup

By default, the application runs in **Demo Mode (Local Storage)**. To connect it globally, select a provider in [app.js](file:///Users/adigoldstone/Desktop/AG Projects/wedding-registry/app.js) under `DATABASE_CONFIG`.

### Option A: Supabase (Real-Time PostgreSQL)
1. Create a free project at [supabase.com](https://supabase.com).
2. Run this query in the Supabase **SQL Editor** to create the tables:
   ```sql
   create table registry_claims (
     id bigint generated by default as identity primary key,
     item_id integer unique not null,
     claimed boolean default false,
     claimer_name text,
     claimer_email text,
     created_at timestamp with time zone default timezone('utc'::text, now()) not null
   );

   -- Enable Realtime events for this table
   alter publish to supabase_realtime add table registry_claims;
   ```
3. Update [app.js](file:///Users/adigoldstone/Desktop/AG Projects/wedding-registry/app.js) configuration:
   ```javascript
   const DATABASE_CONFIG = {
     provider: 'supabase',
     supabase: {
       url: 'YOUR_SUPABASE_PROJECT_URL',
       anonKey: 'YOUR_SUPABASE_ANON_KEY',
       table: 'registry_claims'
     },
     // ...
   };
   ```

### Option B: Firebase Firestore (Real-Time NoSQL)
1. Create a Firebase Project at [console.firebase.google.com](https://console.firebase.google.com).
2. Create a **Firestore Database** in production or test mode.
3. Obtain your web app configuration credentials.
4. Update [app.js](file:///Users/adigoldstone/Desktop/AG Projects/wedding-registry/app.js) configuration:
   ```javascript
   const DATABASE_CONFIG = {
     provider: 'firebase',
     firebase: {
       apiKey: "YOUR_API_KEY",
       authDomain: "YOUR_PROJECT_ID.firebaseapp.com",
       projectId: "YOUR_PROJECT_ID",
       storageBucket: "YOUR_PROJECT_ID.appspot.com",
       messagingSenderId: "YOUR_SENDER_ID",
       appId: "YOUR_APP_ID"
     },
     // ...
   };
   ```
